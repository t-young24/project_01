# 세라젬 웰라운지 고객 셀프 문진 태블릿 — 기능 명세

세라젬 웰라운지 매장에 설치된 태블릿에서, 대기 중인 고객이 스스로 불편한 부위를 입력하고
체험존을 고른 뒤, 결과를 매니저에게 전달하고 체험 후 건강 체크 결과를 확인하는 화면 프로토타입입니다.

- 대상: 60대 이상 고령층 비중이 높은 고객
- 기준 화면: 태블릿 가로 1280 × 800
- 설계 원칙: **글자 크게 · 버튼 크게 · 한 화면에 할 일 하나 · 뒤로가기 항상 노출**

## 1. 폴더 구조

```
세라잼/
├─ index.html              화면 구조 (HTML)
├─ css/
│   └─ style.css           전체 스타일
├─ js/
│   ├─ config.js           문구 · 체험존 · 제품 · 설정값 (코드 몰라도 수정 가능)
│   └─ app.js              동작 로직
├─ data/
│   └─ measurements.json   세라체크존 측정 결과 (측정기기가 갱신하는 파일)
├─ 실행.bat                 로컬 서버 실행 + 브라우저 열기
└─ README.md               이 문서
```

| 바꾸고 싶은 것 | 파일 |
|---|---|
| 환영 멘트, 자동 전환 시간, 매니저 호출 대기 시간, 최대 부위 수 | `js/config.js` 상단 |
| 체험존 이름 · 설명 · 비치 제품 목록 | `js/config.js` → `ZONES` |
| 부위별 추천 가중치 | `js/config.js` → `PART_WEIGHT` |
| 리모컨 버튼 설명 | `js/config.js` → `REMOTE_GUIDE` |
| 측정 데이터 주소 / 예시 데이터 | `js/config.js` 하단 |
| 색상 · 글자 크기 · 버튼 크기 | `css/style.css` (`:root` 변수) |
| 화면 문구, 인체모형 · 리모컨 SVG | `index.html` |
| 화면 전환, 선택 로직, 정상/주의/위험 판정 기준 | `js/app.js` |

## 2. 실행 방법

### PC에서 확인
`실행.bat` 더블클릭 → 로컬 서버가 켜지고 브라우저가 `http://localhost:8000` 으로 열립니다.
(`F11` 전체화면으로 보면 태블릿 느낌에 가깝습니다.)

> 파일을 직접 더블클릭(`file://`)해서 열면 화면은 나오지만, 측정 데이터 `fetch`가 브라우저 정책으로
> 차단되어 6단계가 "예시 데이터"로 표시됩니다. 반드시 서버를 통해 여세요.

### 태블릿에서 확인
PC와 같은 와이파이에서 `실행.bat` 실행 후, 태블릿 브라우저에서 `http://<PC IP>:8000` 접속
(PC IP는 `ipconfig` 로 확인)

### 매장 키오스크 모드
```
chrome.exe --kiosk "http://localhost:8000"
```

### 음성 안내 주의
Chrome은 사용자가 화면을 한 번 터치하기 전까지 음성 재생을 막습니다.
첫 화면에서 음성이 안 나오면 화면을 한 번 터치하면 안내가 시작됩니다.

## 3. 전체 흐름 (6단계)

```
1 시작 → 2 부위 선택 → 3 체험존 추천 → 4 매니저 전달 확인 → 5 리모컨 안내 → 6 결과 리포트
```

상단 바(모든 화면 공통)
- `◀ 이전` — 큰 뒤로가기 버튼 (1단계에서는 비활성)
- 1 ~ 6 단계 표시 (현재 단계 파란색, 지난 단계 연파랑)
- `🔊` 음성 안내 켜기/끄기
- `⌂ 처음으로` — 모든 상태 초기화 후 1단계로

---

### 1단계 — 시작 화면
- 진입과 동시에 환영 음성 안내 재생 (`WELCOME_TEXT`)
- 화면 문구: "불편하신 부분을 선택해주세요"
- **자동 전환**: 음성 안내가 끝난 뒤 `START_WAIT_MS`(기본 20초) 동안 진행 바 표시 후 2단계로
- `시작하기 ▶` 버튼으로 즉시 이동 가능

### 2단계 — 인체모형 부위 선택
- 정면 인체모형(SVG)을 큰 구획으로만 단순화: 머리 · 목 · 어깨 · 팔 · 등 · 허리 · 골반 · 무릎 · 다리
- 좌/우, 위/아래 도형은 **각각 따로 터치·하이라이트**되지만, 라벨과 목록에는 좌우 구분 없이 통일된 이름만 표시
  (예: 왼쪽·오른쪽 다리를 모두 골라도 목록에는 "다리가 아파요" 한 줄)
- 부위 터치 → 오른쪽 패널에 강도 선택 카드
  `1단계 약함 / 2단계 보통 / 3단계 심함` (색상 초록/노랑/빨강)
- 조사 자동 처리: "등**이** 얼마나 불편하세요?", "다리**가** 얼마나 불편하세요?"
- 최대 **5개 부위**(이름 기준) 선택, 초과 시 토스트 + 음성 안내
- 선택된 도형을 다시 누르면 그 도형만 취소, 목록의 `✕`는 같은 이름 도형 모두 취소
- 선택 목록은 오른쪽에 항상 표시, `선택 완료 ▶`로 다음 단계

### 3단계 — 체험존 추천 (다중 선택)
- 선택한 부위 × 강도로 점수를 계산(`PART_WEIGHT`)해 상위 1 ~ 2개 존을 카드로 추천
  (`가장 추천` / `함께 추천` 배지, "허리 · 등 불편에 도움이 돼요" 근거 표시)
- 체험존: **척추존 · 휴식존 · 순환존 · 뷰티존** — 각 카드에 한두 줄 설명 포함
- `다른 체험도 보고 싶어요 ▼` → 추천과 무관하게 4개 존 전체를 설명과 함께 표시 (안마의자 원치 않는 고객 대응)
- **체크박스 방식 다중 선택**, 선택한 존은 하단에 칩 목록으로 계속 표시
- `선택 완료 ▶` → 문진 결과(부위·강도·선택 존·추천 존)를 매니저에게 전달(현재 `console.log`)

### 4단계 — 매니저 전달 확인
- "선택하신 체험이 담당 매니저에게 전달되었어요" 안내 배너
- 선택한 존마다 카드: 존 이름 · 짧은 설명 · **자세한 설명** · **비치된 세라젬 제품 목록**
- `확인했어요 · 체험 시작 ▶` 버튼 하나로 다음 단계
- **테이블오더 방식 매니저 호출**: 이 화면에 `MANAGER_WAIT_MS`(기본 30초) 머물면 안내창 표시
  - "잠시 후 담당 매니저가 체험 안내를 도와드리겠습니다" + 음성
  - 접수 번호 · 선택한 체험 · 상태(매니저 호출됨 · 대기 중)
  - `네, 기다릴게요`(닫기) / `🔔 매니저 다시 호출`
  - 다른 화면으로 이동하면 타이머 취소 · 창 자동 닫힘

### 5단계 — 체험 중 리모컨 안내
- 상단 배너 `❓ 버튼 사용법이 궁금하면 여기를 눌러 다시 확인하세요`
- 리모컨 그림(SVG)의 7개 버튼에 번호 표시, 오른쪽에 번호 · 아이콘 · 큰 글씨 설명 매칭
  1 전원 · 2 시작/멈춤 · 3 강도 조절 · 4 온열 · 5 시간 · 6 모드 선택 · 7 매니저 호출
- 배너를 누르면 음성 설명과 함께 버튼이 순서대로 2.6초씩 강조
- `체험 끝 · 결과 보기 ▶` → 6단계

### 6단계 — 세라체크존 결과 리포트 (체험 종료 후)
- 측정 데이터를 `MEASURE_API_URL`에서 **실제 `fetch`로 불러옴** (기본: `data/measurements.json`)
  - 성공: 하단에 측정 시각 표시
  - 실패(파일 없음 · 서버 꺼짐 · `file://`): 예시 데이터로 대체하고 **"⚠ 측정기기와 연결되지 않아 예시 데이터를 보여드리고 있어요"** 명시
- 항목: 혈압 · 맥박 · 스트레스 · 체지방 · 근육량 · 체온 (6개)
- **간단 설명(항상 표시)**: 3열 카드 — 값 · 초록/노랑/빨강 게이지 · `정상/주의/위험` 칩 · 한 줄 쉬운 설명
- **자세히 보기(버튼을 눌러야 펼침)**: 항목별 아코디언 —
  이번 측정값 · 정상 범위 · 내 위치(구간 바) · 이렇게 관리해보세요(관리 팁)
- 문구는 모두 "체험을 마치고 집에 가기 전" 상황에 맞춤 (예: "나가실 때 겉옷을 챙기세요")
- 하단 왼쪽 `📱 결과표 가져가기` → QR 창
  - QR 모양 패턴(프로토타입용 가짜) + 결과표 번호(`MMDD-0000`)
  - `확인했어요`로 닫기
- 하단 오른쪽 `처음 화면으로 ⌂` → 상태 초기화 후 1단계

## 4. 데이터 · 연동 지점

### 세라체크존 측정 데이터 (`data/measurements.json`)
```json
{
  "measuredAt": "2026-09-11T14:32:00+09:00",
  "bloodPressure": { "sys": 124, "dia": 79 },
  "pulse": 68,
  "stress": 42,
  "bodyFat": 26.3,
  "muscle": 27.1,
  "bodyTemp": 36.5
}
```
- 측정기기 PC가 이 파일을 덮어쓰면 화면에 바로 반영 (캐시 방지 처리됨)
- 기기 서버가 따로 있으면 `config.js`의 `MEASURE_API_URL` 변경, 또는 주소 뒤에 `?api=http://...` 지정
- 필수 항목이 숫자가 아니면 형식 오류로 처리되어 예시 데이터로 대체

### 판정 기준 (`app.js` → `interpret()`)
| 항목 | 정상 | 주의 | 위험 |
|---|---|---|---|
| 혈압 (수축/이완) | < 130 / < 85 | ≥ 130 또는 ≥ 85 | ≥ 140 또는 ≥ 90 |
| 맥박 (회/분) | 55 ~ 90 | 50 ~ 54, 91 ~ 100 | < 50, > 100 |
| 스트레스 (점) | < 50 | 50 ~ 74 | ≥ 75 |
| 체지방 (%) | < 28 | 28 ~ 34.9 | ≥ 35 |
| 근육량 (kg) | ≥ 24 | 20 ~ 23.9 | < 20 |
| 체온 (°C) | 35.5 ~ 37.2 | 37.3 ~ 37.7 | < 35.5, ≥ 37.8 |

> 프로토타입용 기준값입니다. 실제 적용 시 의료 자문을 거쳐 조정이 필요합니다.

### 아직 연결되지 않은 부분 (현재는 `console.log`로만 기록)
| 기능 | 현재 | 연동 시 |
|---|---|---|
| 문진 결과 매니저 전달 (3단계 완료 시) | `[매니저 전달]` 콘솔 출력 | 매니저 단말/서버로 `fetch` POST |
| 매니저 호출 / 재호출 (4단계) | `[매니저 호출]` 콘솔 출력, 접수 번호는 임의 2자리 | 호출 서버 연동, 서버 발급 번호 사용 |
| 결과표 QR (6단계) | 가짜 패턴 `drawFakeQr()` | 서버에 결과 저장 → URL을 QR 라이브러리(예: qrcode.js)로 생성 |
| 세라체크존 측정 데이터 | JSON 파일 `fetch` (연동 구조 완성) | 기기 소프트웨어가 JSON을 쓰거나 HTTP로 내보내기만 하면 됨 |
| 음성 인식 (STT) | 미구현 (음성 **안내** TTS만 동작) | Web Speech API `SpeechRecognition` 또는 외부 STT |

## 5. 기술 사항
- 순수 HTML / CSS / JavaScript, 외부 라이브러리 없음
- 인체모형 · 리모컨 · QR 패턴 모두 SVG로 직접 구현
- 음성 안내: Web Speech API `SpeechSynthesis` (ko-KR, 속도 0.88)
- 디자인 토큰: 베이지 배경 `#f7f3ec`, 딥블루 포인트 `#2f6db5`, 본문 22px, 버튼 최소 72px (주요 버튼 96px)
- 화면 전환: 0.55초 페이드 + 슬라이드
- 로컬 서버: Python 내장 `http.server` (별도 설치 불필요, Python만 있으면 됨)
