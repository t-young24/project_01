# 나레이션 mp3 넣는 곳

이 폴더에 `scene1.mp3` ~ `scene7.mp3` 를 넣으면 홍보영상이 브라우저 음성 대신 이 파일을 재생합니다.
(파일이 있는 장면만 mp3, 없는 장면은 브라우저 음성)

| 파일 | 장면 | 읽을 문장 (docs/홍보영상_대본.md 나레이션 전문과 동일) |
|---|---|---|
| scene1.mp3 | 문제 제기 | 매장을 찾은 고객에게, 매니저는 같은 질문을 처음부터 다시 묻습니다. 워크인 고객 한 분의 니즈를 파악하는 데만 평균 18분. |
| scene2.mp3 | 타이틀 | 그래서 만들었습니다. 고객이 태블릿에서 직접 불편한 곳을 고르고, 그 내용이 매니저에게 실시간으로 전달되는 셀프 문진. |
| scene3.mp3 | 고객 화면 | 60대 이상 고객도 어렵지 않게. 큰 글씨, 큰 버튼, 그리고 화면마다 할 일은 하나뿐입니다. 불편한 부위를 누르고 강도를 고르면, 딱 맞는 체험존을 추천해 드립니다. |
| scene4.mp3 | 실시간 전달 | 고객이 선택을 마치는 순간, 매니저 태블릿에 응대카드가 도착합니다. |
| scene5.mp3 | 응대카드 | 카드에는 불편 부위와 강도, 지난 방문 기록, 그리고 오늘의 응대 포인트가 정리되어 있습니다. 매니저가 응대 시작을 누르면, 고객 화면에는 바로 담당자 배정 안내가 뜹니다. |
| scene6.mp3 | 결과·효과 | 체험이 끝나면 세라체크 결과까지 쉬운 말로 안내합니다. 니즈 파악 시간은 절반 이하로, 남는 시간은 더 많은 고객에게. |
| scene7.mp3 | 클로징 | 묻지 않아도, 이미 알고 있는 응대. 세라젬 웰라운지 셀프 문진입니다. |

- 무료로 만들 수 있는 곳: Vrew(브루), 클로바더빙, 타입캐스트 — 문장을 붙여넣고 "음성 다운로드(mp3)"
- 장면 길이는 mp3 길이에 맞춰 자동으로 늘어납니다 (mp3 가 장면 최소 길이보다 길면 mp3 가 끝날 때까지 기다림)
- 파일을 넣은 뒤 git 으로 올려야 GitHub 사이트에서도 재생됩니다
